# 🍱 Marmitaria Dona Rita - Cardápio Digital

Este projeto consiste na reestruturação e modernização completa de uma aplicação acadêmica, transformando-a em uma plataforma interativa voltada para negócios reais e com identidade visual focada em experiência do usuário.

## 🚀 Funcionalidades
* **Interface Moderna:** Layout totalmente adaptado para o Modo Escuro (Dark Mode), garantindo conforto visual.
* **Simulador de Pedidos:** Sistema inteligente que calcula dinamicamente o valor estimado da marmita com base no tamanho selecionado e nos adicionais escolhidos de forma instantânea.
* **Responsivo:** Desenvolvido com foco na usabilidade em dispositivos móveis e desktops.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica e acessível da página.
* **CSS3:** Estilização avançada utilizando variáveis de cor para o gerenciamento do tema escuro e layout limpo.
* **JavaScript Nativo:** Manipulação de DOM para escuta de eventos e atualização dos valores em tempo real sem necessidade de recarregar a página.
